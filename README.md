# mireu.org

Portfolio site for Yohan Mireu Lee. Plain static files, no build step needed to host it.

- `index.html` — the page shell
- `css/site.css` — styles
- `js/app.js` — everything else (carousel, 3D viewer, sound), bundled with three.js
- `assets/models/` — one compressed 3D model per project (.glb)
- `assets/img/<project>/` — gallery images, numbered in page order
- `assets/covers/` — the carousel tiles

To publish: put the contents of this folder at the root of the `mireu.org` GitHub repository and turn on GitHub Pages for the main branch.
